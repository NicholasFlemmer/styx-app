Styx

Desktop app (macOS, Windows) that switches between projects in one window, embeds an editor, supervises coding-agent sessions, and gates agent access to deploy and server targets. Target stack: Electron + React.

FidelityHigh. Colors, type, spacing and copy in Styx.dc.html are final for v1. Recreate in React; do not ship the prototype HTML. FilesStyx.dc.html (interactive prototype, all screens and states) · styx-tokens.json / styx-tokens.css · Wireframes.dc.html (lo-fi history) · UX Research Memo.dc.html Frame1280 × 800 design size. Minimum window 1100 × 680. Layout is fluid horizontally; fixed-width panes are listed in §3. AestheticBrutalist: 1px hairlines, zero radius, zero shadows, uppercase tracked labels, tabular numerals, one accent used only for "needs you" and "prod".

Six objects. UI copy uses these names exactly; nothing else is introduced.

Session state machine

idle ──start──▶ working ──ask | needs-grant──▶ needs-you ──approve | reply──▶ working
                  │                                 └──deny──▶ working (agent adapts; no reason required)
                  ├──finish──▶ done (kept 7 days, then archived)
                  └──error (cli-missing | conflict | auth-expired)──▶ paused ──resolve──▶ working
needs-you never times out; the badge persists until answered.

Grant state machine

requested ──policy match──▶ active                     logged "auto: policy #n"
requested ──user grant (+MFA when env=prod and scope∋write|deploy|delete)──▶ active
requested ──user deny──▶ denied
active ──expiresAt | idle 1h | session end | user revoke──▶ revoked   token invalidated, logged
One requested grant per session at a time; further requests queue. "always" never expires, is listed as persistent, revocable from any lock glyph.

Space, shape, motion

  • 4px base. Pane padding 12–16px; table rows 14px 20px; cells 8–10px. Buttons: compact 5px 10px, regular 6px 12px, footer rows 14px tall full-width. Minimum hit target 28px; footer buttons 44px.
  • Radius 0 everywhere except macOS traffic lights (50%). Shadows none. Floating surfaces get a 1px --tx border instead.
  • Motion: sheet slides in 160ms cubic-bezier(.2,.8,.2,1); modals and toast fade/slide 120–160ms; hover instant; caret blinks 1s stepped. prefers-reduced-motion: fades only.
  • Two selection vocabularies. data-inv (inverted) = "current": tabs, nav, lanes, palette row, files, chosen IDE, checked step. data-on (accent) = "attention or armed": needs-you, PROD, chosen duration, policy on, selected repo checkbox.

4. Screens

4.1 Workspace (default)

Files 200px · Editor fluid · Chat 360px. Editor stack: tab row 34px → code → hunk bar 40px (present only when an agent has pending hunks) → terminal 130px (drag-resizable, collapsible) → status bar 26px. Engine: Monaco. Agent hunks render with --add line background and a right-aligned AGENT · AGE label; hunk bar: Accept all (primary) / Review (opens Diff review) / Reject. Files footer: "Open in {IDE}" launches the fallback editor on the current worktree.

Chat: session tabs (3 visible, rest in ▾; needs-you tab shows accent !), meta line (agent · branch · age · "waiting on you"), transcript, composer (min 56px; @file, /command, Model ▾; ⏎ send, ⇧⏎ newline). User messages --tx-filled right-aligned; agent messages hairline-bordered; file lists and decisions are bordered blocks with inline buttons. Access requests render as an accent-bordered card with an accent header and Review request / Deny. ⤢ pops the chat out (§4.11).

4.2 Home (All projects)

Counter strip (Numeral L ×4: needs you, agents working, grants active, projects) → project table (project with status square, path, branch, agents, targets, last activity; row click opens Workspace) → add row (Open folder, Clone URL) → Activity feed (mono, newest first). Empty: headline "No projects yet.", one line, Scan this machine (primary) / Open folder / Clone URL.

4.3 Agents (board)

Three equal columns: Needs you (label accent-filled), Working (includes idle), Done. Header: label + Numeral M count (zero-padded). Card: agent + age, project · branch (mono), note, action row; needs-you cards add Deny. Dashed "Spawn agent" under Working opens the spawn modal. Empty texts: "Nothing waiting on you." · "No agents running. Spawn one below, or ask in the palette." · "Finished sessions land here for 7 days."

4.4 Repo (Worktrees)

Header: Worktrees, remote + ahead/behind, Fetch, + Worktree (primary). Table: branch (mono 500), owner (dot + name), changes, PR, action. Selected lane inverted; unified diff of the selection below. Conflict: changes reads CONFLICT · file vs main, action becomes Resolve, owner dot stays; the owning session is paused.

4.5 Approvals

Tabs Inbox · N / Policies / Audit log; Policies pane 380px always on the right. Inbox row: agent, project, → target, ENV tag (accent when prod), SCOPE tag, quoted reason (mono), age; Review (primary, opens that session with the sheet) / Deny. Footer line: auto-approved count. Policies: 16px checkbox (accent when on), rule, mono meta; + Rule, Export JSON. Audit rows open the entry drawer (§4.8).

4.6 Settings

Nav 220px: App group (General, Editor, Agents & CLIs, Keychain & secrets, Policies, Shortcuts) and Project · name group (Targets, Agent defaults, Env & secrets); footer notes .styx/project.json. Targets is a table (target, ENV, policy select 170px, state mono, action). Other sections: label/value rows with a select on the right (min 140px). Project values that override app defaults show a reset affordance.

4.7 Diff review

Header: Review, meta (agent · branch · a accepted · r rejected · p pending), Accept all / Reject all / Done (primary). Files 220px with +N counts and a Keys legend. Each hunk: --s1 header (file, range, status tag, Accept / Reject) and code body. Accepted → status tag accent-filled, Accept inverted; rejected → Reject inverted. Done applies accepted hunks to the worktree and returns to Workspace; pending stays pending. Keys: a / r / j / k / Mod+⏎.

4.8 Audit entry drawer

380px over the Approvals content, --bg, --tx left border. Header label + ✕; action as title (20px); time · actor → target (mono); rows: Actor, Target, Scope, Duration, Session, Worktree, Triggered by (command), Policy. Footer: Copy JSON / Revoke now (disabled when already revoked or system-issued).

4.9 Onboarding

Covers everything below the titlebar; the rail and nav are hidden until it finishes. Step strip: 01 Editor · 02 Projects · 03 Agents · 04 Targets (current inverted). Footer: Back · Skip · Continue/Finish (primary). Skip on any step goes to Home.

  • Editor. Detected IDEs (VS Code, Cursor, JetBrains, Neovim) with version/location, importable items, and a role tag; the chosen row is the "Open in…" fallback. Toggles: Import keybindings, Import theme & font, Import recent folders (feeds step 2), Install "Open in Styx" command. Styx's own editor is always the embedded default.
  • Projects. Repos found by scan and IDE recents; checkbox (accent), path, remote/branch. Unchecked by default when no remote and stale. Add folder / clone URL row.
  • Agents. Detected CLIs with version, auth state ("signed in", "Sign in →", "Install →"), health dot (accent when missing). Sign-in defers to each CLI's own flow.
  • Targets. Provider grid (Vercel, AWS, GCP, Supabase, GitHub, SSH host) with method label; each opens the connect modal (§4.10). Optional; Finish available regardless.

4.10 Connect target (modal, 560)

Step 1 provider grid. Step 2 by method. OAuth (Vercel, Supabase, GitHub): explanation, Environment chips (prod / staging / preview), "Waiting for browser…" mono line, Back / Open browser. IAM / key (AWS, GCP): Name, Access key or service account, Secret (masked, never re-shown), Environment; Back / Test connection / Save to Keychain (Credential Manager on Windows). SSH: Host, User, Key path with Browse, Environment; Back / Test connection / Save. Explanatory copy per method is in the prototype and is final.

4.11 Spawn agent (modal, 600)

Header label "Spawn agent · project". Five agent tiles (name, version); chosen inverted. If the chosen CLI is missing, an inline error row appears (accent square, text, Install guide / Locate binary) and Spawn is disabled. Fields: Worktree (New from main ▾), Branch (auto agent/<name>-<n>, editable), First message (textarea), toggles: Auto-approve edits (off), May request targets (on), Notify when it needs me (on). Footer: Cancel / Spawn · Mod+⏎. Spawning creates the worktree, starts the CLI, opens Workspace on that session.

4.12 New project (modal, 600)

Greenfield entry point, reachable from the rail "+", Home ("+ New project" and the empty state), onboarding step 2, and the palette ("New project…"). Fields: Name; Location (default ~/code/<name>, C:\dev\<name> on Windows, Browse). Start from, three tiles: Empty folder (git init + README) · Template (built-ins: Node, Python, Go, Rust, static; plus repos tagged styx-template in the user's GitHub org) · Agent scaffolds it (brief textarea; the chosen default agent builds the skeleton in an empty worktree on main, then pauses in needs-you before the first commit). Toggles: git init (on), Create GitHub repo · private (on when a GitHub target exists; otherwise the row reads "Connect GitHub to create the remote" and links to §4.10), Copy targets from {current project} (off), Open in {IDE} too (off). Footer: Cancel / Create (· spawn {agent} when the agent option is chosen). Result: project appears in rail and Home; agent option lands in Workspace on the new session.

4.13 Pop-out chat window

Separate OS window (400 × 500 default, resizable, remembers position per session). Own titlebar with platform chrome, agent name, project · branch, Dock button. Same transcript/composer as the pane. Docking returns it to the chat pane; closing the main window closes pop-outs.

4.14 Notifications

In-app toast (340px, top-right under the titlebar, 8s or until action): accent header "Needs you · Styx · now", title (agent wants target · scope), mono meta, Review / Later. macOS: dock badge = count of needs-you sessions, single bounce on first request, menu with recent requests and Do Not Disturb. Windows: tray icon with accent dot; Action Center toast with the same two actions; left-click opens the Agents board. No sound by default; "Badge + sound" is a setting.

4.15 Error states

  • Auth expired (target health): banner "AWS acme-prod: credentials expired 2h ago. Agents requesting it are paused." → Reconnect opens connect modal on that provider's key step. Target row state reads expired.
  • CLI missing: banner "codex not found on PATH. 1 session cannot start." → Install guide (onboarding step 3). Spawn modal shows the inline error; board card shows paused.
  • Merge conflict: banner "fix/checkout conflicts with main in checkout.ts. Claude is paused until resolved." → Resolve opens Repo with the lane selected; lane shows CONFLICT.

5. Command palette

Mod+K anywhere; also the titlebar field and project button (Projects scope). 640px, --tx border, mono prompt with accent >. Groups: Actions, Agents, Projects; first row inverted; ↑↓ move, ⏎ run, Mod+⏎ run in new window, ⇥ cycles scope, Esc closes. Every row that can be blocked by a grant shows lock state in its meta (e.g. "open · 58m", "needs you"). Verbs: switch, open, spawn, ask, deploy, grant, revoke, diff. Fuzzy match on label and meta.

9. Accessibility

  • Contrast: --tx on --bg 15.6:1 dark / 15.1:1 light; --mu on --bg 5.4:1 / 5.6:1; --acx on --ac 16:1 / 14:1; --act on light --bg 4.6:1. Never use --ac as text on light.
  • Colour is never the sole signal: needs-you also has the ! badge and "waiting on you" text; PROD is a text tag; selected rows are inverted, not tinted.
  • Focus: visible 1px --ac outline on every control; focus trapped inside modals and sheet; Esc returns focus to the invoker. Palette input autofocused; results are a listbox with aria-activedescendant.
  • Live regions: the board's Needs-you count and toasts announce via aria-live="polite"; grant results announce "Granted Codex read, write on Supabase prod for 1 hour".
  • Terminal and editor expose their own accessible modes (Monaco screen-reader mode, xterm.js accessibility tree). Uppercase labels use text-transform, not capitalised source, so screen readers read words.
  • All hit targets ≥ 28px; footer actions 44px. Keyboard parity per §6. Reduced motion respected.

11. Out of scope for v1

  • Linux build; team sync of policies (per-machine JSON export only); custom themes beyond dark/light/system; more than 4 visible agent tabs; extension marketplace (Monaco only, VS Code as fallback).
