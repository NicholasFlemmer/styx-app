Tasks: the project's lanes, side by side

Most projects have nothing to preview, so the centre opened on an empty page. Tasks becomes the first instrument: every lane running in this project as a live tile, each answerable where it stands. The chat keeps the lane you are focused on; the tiles hold the rest, so you can keep three agents moving without switching.

Tasks first, then PreviewTasks · Preview · Changes · Code · Terminal. A project with a dev server still opens on Preview; one without opens on Tasks.
A tile is a small laneIts task, whose turn, what it is doing now or its last result on paper, and a one-line reply. A question is answered on the tile.
The chat is the lane in focusIts tile is outlined “In the chat”. Click any other tile's head to bring that lane into the chat. Nothing else moves.
