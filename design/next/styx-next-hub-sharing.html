Sharing: any file, a link anyone can open

Phase 2 of the team hub (ADR-0032). Share any file or folder from Styx and get a link: for the team, or for anyone. Home base shows each kind of file the way it should be seen: images, video, PDFs, data, code, whole websites, and gives every one a review thread and versions.

Every file typeUp to 2 GB each. Proper previews for the common kinds; a clean download card for the rest.
Links you controlTeam or anyone with the link; expires in a day, a week, a month or never; revoke in one click.
Safe to openShared files are served from their own address, so an uploaded page can never touch anyone's hub session.

A. From the pilot seat: Share, then Copy link

A Share button on the lane. Drop any files or a folder, or pick from what the lane made. Choose who can open it and for how long. It uploads with progress and the link is on your clipboard when it lands. Agents do the same with hub_share.
