2. Starting a task: say it, Styx works out the rest

One sentence is enough. Styx guesses the project, the apps it will need and what will need your OK, and shows its guess before it starts so you can correct it. Developers can still pick the branch and the AI; nobody else has to see those choices.

  • The guess is the plan in plain words: it will read, it will draft, it will ask before spending.
  • More options holds the developer controls: which AI, which branch, design first or straight to code.

12. A project: everything for one client or product

Projects stay the backbone of Styx. A project holds its code (the repo, its branches, the live site and preview), the apps it uses, its tasks of every kind, its own rules and know-how, and its people. Home shows everything; a project shows one client's or product's world, and every new task started here belongs to it.

  • Code keeps today's project essentials: repo and folder, main branch, open branches per task, checks, run locally, open in your editor.
  • A project without code works too (The Promo Group: ads and email only); the Code box simply is not there.
  • Tabs reach the full lists; the overview is what a person needs at a glance.
