---
title: Settings
description: Every setting on the Settings screen, what it does, its default, and whether it is saved on this machine or in the project.
---

Settings has two groups. **App** settings are yours and stay on this machine; open them with **Settings** in the rail. **Project** settings (**Targets**, **Agent defaults**, **Env & secrets**) belong to one project and are opened from that project's nav. A few rows in the App sections apply to the current project; they're marked below.

Where a value is kept:

- **This machine**: Styx's local database. Not shared with anyone.
- **project.json**: the project's `.styx/project.json`, which you commit, so everyone on the project gets it. Secrets never go there. See [project.json](/docs/reference/project-json).
- **Keychain**: the macOS Keychain, Windows Credential Manager or the system keyring on Linux.

In **Agent defaults**, a **Reset** button appears next to a value the project has set; it puts the default back.

## Project

### Targets

A table of the project's deploy and server targets: **Target**, **Env**, **Policy**, **State**. Credentials stay in the keychain on this machine. Targets listed in `.styx/project.json` show up here as unconnected until you connect them.

| Setting    | What it does                                                                                                              | Default                                                               | Kept         |
| ---------- | ------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- | ------------ |
| **Policy** | Per target. **Ask · MFA** (ask, then Touch ID, Windows Hello or system password), **Ask each time**, or **Always allow**. | Ask · MFA for `prod`, Always allow for `scm`, Ask each time otherwise | This machine |

Row actions: **Refresh** (targets that use a provider CLI login), **Revoke** (end the open grant), **Edit** or **Connect**, and **Remove**, which needs a second press (**Remove?**) because it deletes the credential and ends the target's grants. Under the table: **+ Connect target · OAuth / key / SSH** and **Deploy commands…**. When the project file sets target policies or rules this machine hasn't accepted, **Accept project policies** appears. See [Connect a target](/docs/access/connect-a-target).

| **Model**                                                         | The model, from the default agent's list. **Default** leaves it to the agent.                                                                    | Default                           | project.json |
| **Auto-approve edits**                                            | Whether a new task starts with **Auto-approve edits** on.                                                                                        | Off                               | project.json |
| **Permission mode**                                               | **Ask each time**, **Accept edits**, **Plan mode**, **Bypass permissions**, **Don't ask** or **Auto**.                                           | Auto                              | project.json |
| **Styx tasks · Run locally, Deploy, Tech debt audit, merges**     | The permission mode for the tasks Styx starts itself. Same six options.                                                                          | Bypass permissions                | project.json |
| **Effort**                                                        | How hard the agent thinks, from the agent's own list. Shown only for agents that take an effort.                                                 | Default                           | project.json |
| **Fetch before cutting a lane**                                   | Fetch from the remote before a new task's branch is created, so it starts from the latest code.                                                  | On                                | This machine |
| **Bring in the base branch before publishing**                    | Merge the base branch into a lane before it is pushed or opened as a pull request.                                                               | On                                | This machine |

| **Checks before landing**                                         | The command Land runs in the lane first (and Styx after a merge it resolved). Typed; blank clears it. Learned by the agent at the first landing. | Not known yet                     | project.json |
